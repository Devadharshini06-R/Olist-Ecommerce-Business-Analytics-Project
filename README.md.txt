# Olist E-commerce Business Analytics Project

## 📌 Overview
This project analyzes the Brazilian Olist E-commerce dataset to generate business insights using SQL, Python, and Power BI.

## 🎯 Objectives
- Analyze sales performance
- Track customer behavior
- Measure business KPIs
- Build interactive dashboards
- Provide business recommendations

## 🛠 Tools
- SQL
- Python
- Power BI
- Excel
- Git & GitHub
